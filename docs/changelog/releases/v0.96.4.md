# v0.96.4

## 功能

- **联系人改为按分组管理**：渠道设置收在上方，联系人按自定义分组列在下方，可新建、重命名、删除分组，也可以把联系人移动到分组。组内按平台账号排序，不再跟着最近消息来回跳动。每个联系人的详细设置在卡片里展开，同时只展开一个；也可以按分组批量设置，或整组移动。渠道没连上时，这些设置仍然可以改。

## 修复

- **修复委托把上下文用满后直接失败的问题**：以前会提示缺少调度上下文、无法继续整理。现在会停用后续工具，并要求立刻说明工作为什么没有做完。
- **修复发起审查时「指定 commit」列出别的会话仓库的问题**：现在读取当前会话正在使用的工作树；换会话或换工作树后，不会再留着上一份列表。
- **修复切换人格时把已选模型一起改掉的问题**：人格和模型已经分开选择，换人格会保留当前模型。

## 性能

- **长思维链默认收起**：没有手动展开时不再自动打开。收起时只显示开头一段；正在生成时若手动展开，也只跟随末尾一段，避免几万字把界面卡住。
- **回复变长时少做重复排版**：流式输出不再为了判断气泡宽度把同一段文字反复扫描。
