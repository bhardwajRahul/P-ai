# v0.96.5

## 功能

- **无气泡模式：流式输出时过程段先摊开，输出完再折叠**：生成过程中全部展开，结束后收成只留最后一段；手动展开过的结束时不收回。气泡模式仍默认折叠。
- **转发进会话的内容收成折叠块**：后台 shell、委托完成、会话通知、自动推送等转发内容在会话里默认收起，点开看全文。

## 性能

- **超长思维链展开不再卡界面**：几万到几十万字的思维链改用纯文本渲染，绕开富文本逐行解析。

## 修复

- **修复网页端带本机路径的图片显示不出来的问题**：手机/网页端只是投影、没有这些文件，现在一律向后端取图。
- **修复思维链正文重复显示标题那一行的问题**。
- **修复换段后气泡里留下空白的问题**：过程段折叠或工具切开新段时，旧高度会套在新气泡上。
- **修复流式输出时视口先下跳再弹回的问题**。
- **修复右键重命名会话被限制为当前会话的问题**：现在对本地非系统会话都能改，切走时没输完的标题也不会被收掉。
- **修复改字体保存被拒绝的问题**。
