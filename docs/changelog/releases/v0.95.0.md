# v0.95.0

## 功能

- **对话里能直接运行可交互的 HTML 页面**：代码块写成 ```html:interactive（也支持 preview、widget）后，直接在该条消息里渲染运行，可做图表、小工具、小游戏；工具栏提供重新加载、源码/预览切换、新窗口打开、复制、导出 .html，运行出错会在卡片底部显示错误横幅。
- **沙箱可以嵌入本地文件**：在页面或对话里写 `<agent-embed src="绝对路径">`，即可把本地 .html / .svg 页面嵌进来渲染，代码类文件分段读取显示，超过 512KB 截断，加载失败显示错误占位。
- **恢复「组织」页，人格上下级可点选修改**：在智能体分组下恢复组织页，用关系图展示人格的上下级多父结构，点选某个节点后勾选它的直属下级，草稿保存；切页前有未保存确认。
- **选下级时上级置灰禁用，不再能勾成环**：人格的委托人与组织页勾选下级时，已在其上级链上的项保留显示但禁用并标注「上级」，不会再勾出环形关系、保存时被悄悄裁掉。
- **会话边栏底部加入深浅色快速切换按钮**：在会话列表底部一键切换深色 / 浅色主题，图标随当前主题变化。

## 修复

- **新增供应商时，保存不再把已选好的供应商或模型顶掉**：以前新增一个供应商（尤其是还没填模型就保存）会牵连到当前选中的供应商或模型，把它悄悄换成列表里的第一个；现在新增只新增，不影响原来的选择，供应商也可以暂时不配模型。
- **移除供应商列表里会误导人的「默认」徽标**：该徽标实际反映的是「上次操作过的端点」，并不代表当前默认供应商，容易让人误判，现直接去掉。
