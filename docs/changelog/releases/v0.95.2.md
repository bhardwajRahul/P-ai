# v0.95.2

## 功能

- **文件标签栏重做外观与关闭操作**：标签由胶囊形改为固定圆角矩形，切换文件时形状不再忽胖忽瘦；文件图标与关闭按钮合并到同一位置，悬停时图标淡出、关闭按钮淡入，点一下即关闭，不再另挂一个悬浮的关闭小按钮。

## 修复

- **修复内置副手无法配置委托模型的问题**：副手被误标成了「系统播报」类隐藏人格，导致它的委托模型配置卡片被拦掉、点不进去；现已纠正标记，副手的委托模型可以正常配置。
- **修复流式输出时文字被裁切、高度跟不上的问题**：内容还在流式生长、换行变高时，展开区域的高度过渡会拦一下，表现为文字被切掉一截、高度慢半拍；现在流式跟随生长期间不再走高度过渡，内容即时撑开。
