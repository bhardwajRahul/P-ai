# v0.96.0

## 功能

- **重做会话侧边栏：新增分组逻辑、重新设计界面**：分组依据改为可切换的「综合 / 项目 / 人格」三种；最近会话按来源（项目 / 频道）聚成块、块间插入可点击跳转的分割线；列表顶部新增「开启新对话」入口；系统通知会话从分组里拿出，收进右下角铃铛按钮；折叠动画重做，快速连点不再状态错乱；列表摘要不再露出反引号、星号、井号等 markdown 标记。
- **项目规则文件支持 CLAUDE.md**：会话读取项目准则时优先用根目录的 AGENTS.md；没有 AGENTS.md 时改用同目录的 CLAUDE.md，两者同时存在时只用 AGENTS.md、不合并。
- **项目自带的 Skill 会随项目自动生效**：会话把当前项目下的 Skill 目录纳入可用范围，项目同名 Skill 覆盖助理空间的同名项，懒加载并缓存。
- **后台终端磁贴可以直接打断**：运行中的后台终端卡片右上角常驻打断按钮，点一下即终止任务，结束后提示「后台 shell 已被用户打断」。

## 修复

- **修复流式输出时气泡与视口剧烈抖动的问题**：流式生成（尤其是表格、公式）期间气泡尺寸反复跳变、视口高频抽颤；现在流式期间气泡尺寸只增不减、表格与公式边打边稳定渲染、跟随贴底的滚动做合批，抖动消除。
