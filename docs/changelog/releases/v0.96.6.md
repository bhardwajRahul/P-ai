# v0.96.6

## 功能

- **会话右键菜单新增「跳转所在分组」**：最近区里的会话右键多一项，点它跳到下面分类区中该会话所属的人格 / 项目分组并定位展开。
- **标题栏「新建会话」按钮改为常驻**：以前侧边栏展开时会隐藏，现在始终显示在上下文占用圆环左侧。

## 修复

- **修复使用 Grok 供应商时消息发不出去、界面卡住的问题**：这类会话发出的请求会在准备阶段崩溃，界面停在「准备下文」且停止按钮无效；现在能正常发送，中断也生效。
- **修复系统人格与系统角色的消息无法撤回的问题**：现在和其他消息一样能撤回或创建分支，撤回后不会把内容回填到输入框。
- **修复发送过程中不能随时打断的问题**：以前提交请求还没返回时停止按钮不可用，现在任何时刻都能打断；已有内容先优雅保存，超时才硬中止。
- **修复限流重试时界面卡在「准备上下文」的问题**：额度耗尽不再被误当成限流重试，限流重试会显示倒计时。
- **修复 Codex 供应商删掉最后一个模型后详情页整页消失的问题**：另外点进详情不再被误判成「有未保存修改」。
