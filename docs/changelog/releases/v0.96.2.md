# v0.96.2

## 功能

- **发起委托与代码审查合并为一张卡片**：会话菜单里两个入口合成一个，在卡片顶部切换「发起委托 / 代码审查」；两边都能自选模型，卡片记住上次选的面板。
- **最近区和历史区统一样式**：最近区的标题行与下方历史分组统一外观，折叠箭头移到文字后面、悬停才显示；「最近」左侧管展开收起，右侧切换 12 / 24 / 48 / 72 小时的时间窗口。
- **过程消息支持完成后折叠**：同一条回复里已完成的过程消息收成「上 N 条消息」，点开可看全部；不想折叠可以在开关里关掉。
- **优化工具调用的语义化 UI**：工具调用改为「阅读 agentStore.ts #1090-1210」这类动作加文件名的纯文本，右侧显示增减行数；目标文本可直接点击打开本地文件，外部 MCP 工具统一显示为「链接到 {工具名}」。
- **重做思维链折叠区**：思维链标题吸顶，右上角可折叠，展开与收起在上下两端都能操作，折叠时保留 4 行预览。

## 修复

- **修复在还没有任何提交的空仓库里打开 Git 面板与代码审查会报错的问题**：仓库刚初始化、尚无首次提交时，相关功能按空历史正常显示，不再报错。
